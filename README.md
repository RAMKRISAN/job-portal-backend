# Job Portal Backend System 🚀



A robust, scalable RESTful API built with **Java 17** and **Spring Boot**. This system handles the entire lifecycle of job postings and candidate applications.



## 🌟 Key Features

- **Candidate Management**: Register and manage user profiles.

- **Job Inventory**: CRUD operations for posting and managing vacancies.

- **Relational Applications**: Linking users to jobs using JPA @ManyToOne mappings.

- **Dynamic Search**: Keyword-based job discovery with case-insensitive filtering.



## 🛠️ Tech Stack

- **Framework**: Spring Boot (Spring Web, Spring Data JPA)

- **Database**: MySQL

- **Tools**: Hibernate, Maven, Postman

- **Language**: Java 17
